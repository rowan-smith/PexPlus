# Ladder Commands

Ladders are used to define promotion and demotion paths.

## Basic Management

- `/pex ladder <ladder> create`: Create a new ladder.
- `/pex ladder <ladder> delete`: Delete a ladder.

## Promotion/Demotion

- `/pex promote <user> [ladder]`: Promote a user.
- `/pex demote <user> [ladder]`: Demote a user.

## Ladder Structure

- `/pex ladder <ladder> add <group>`: Add a group to the ladder.
- `/pex ladder <ladder> remove <group>`: Remove a group from the ladder.
