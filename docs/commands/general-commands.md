# General Commands

General administrative and utility commands.

## Plugin Management

- `/pex reload`: Reload the plugin configuration, translations, and backends.
- `/pex version`: Show version information and active adapters.
- `/pex debug`: Toggle debug mode for permission resolution logging.

## Backend Management

- `/pex backend list`: List all loaded backends.
- `/pex backend status`: Show current backend health and performance stats.
- `/pex backend switch <backend>`: Interactively switch the active backend.

## Data Management

- `/pex import <source>`: Import data from another permissions plugin or legacy PEX.
- `/pex export <destination>`: Export current data to another format.
