# Requirements

To run PermissionsExPlus, you need the following:

- **Java Version**: Java 21 or higher (Java 25 is recommended and used for builds).
- **Server Platform**: 
  - Spigot (1.13+)
  - Paper (1.13+)
- **Memory**: Minimum 512MB RAM dedicated to the server.
- **Optional**: 
  - Redis (for cross-server synchronization)
  - MySQL, PostgreSQL, or MariaDB (for external database storage)
