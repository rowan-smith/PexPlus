# Prefix and Suffix

Prefixes and suffixes are common options used to display a player's rank in chat or tab lists.

## Setting a Prefix

```bash
/pex user Rowan option set prefix "[Admin] "
```

## Setting a Suffix

```bash
/pex group vip option set suffix " &6[VIP]"
```

## Inheritance

Prefixes and suffixes follow the same inheritance and weight rules as other options. The value from the highest-weighted group will be used.
